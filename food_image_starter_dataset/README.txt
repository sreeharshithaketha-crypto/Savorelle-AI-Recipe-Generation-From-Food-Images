Starter food-image set created from a generated 20-tile food collage.
Images are JPEG and each is below 5 MB.
These are dish-level examples, not verified ingredient-level labels.
For ingredient detection, build a separate dataset with images labeled for visible ingredients (e.g., tomato, onion, potato, rice) and manually verify every label.
Generated images are useful for interface testing and prototyping, but should not be your only training data.
